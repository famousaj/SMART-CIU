# Smart Customer Interface Unit (CIU)

## Overview

This repository contains a proof-of-concept prototype demonstrating a Bluetooth-enabled enhancement for Kenya Power's prepaid Customer Interface Unit (CIU).

The project aims to improve customer convenience by integrating secure Bluetooth communication between the official MyPower mobile application and the Customer Interface Unit while maintaining compatibility with the existing prepaid electricity infrastructure.

## Features

- Secure BLE communication
- Automatic token transfer
- Mobile monitoring
- Low balance notifications
- Prototype demonstration
